00 / About

I learn by breaking things and shipping the fix.

I'm a Computer Science & Engineering student at Reva University, based in Bengaluru. My work sits at the intersection of practical AI products, IoT hardware, and web applications — I'd rather debug a WhatsApp webhook at 2 AM than finish a textbook chapter.

Over the last two years I've shipped a production WhatsApp study bot with payments and referrals (Yukshya), wired up an ESP32-based plant monitor that talks back to you (GreenSync), and built a personal movie library that uses Telegram as cold storage for 5GB+ files (MovieVault). Alongside, I've entered thirteen hackathons, won prizes in two of them, and reached a national round once.

What I care about: architecture that doesn't collapse under its own weight, security that isn't an afterthought, and interfaces people actually use. I write Python, TypeScript, C, and the occasional stubborn bash script.

Yukshya

02 — Embedded × Voice × Agri-tech

GreenSync

A plant that talks back. Multi-sensor ESP32 rig that reads soil, light, and environmental data, computes a Plant Health Index, classifies the plant's state, and triggers one of 14 pre-recorded voice responses through a JQ6500 module. Built after the DFPlayer Mini kept flaking.

Board
ESP32 WROOM-32 · 38-pin dev board · 3.3V logic
Audio Chain
JQ6500 (16Mbit) → PAM8403 amp → speaker · 14 clips (0001–0014)
Logic
Sensor validation → PHI calc → condition classifier → audio cue
Hard-won lessons
GPIO constraints · voltage mismatches · common-ground discipline
Stack
ESP32C++Arduino IDESoil / DHT sensorsPAM8403

03 — Full-stack × Clever storage

MovieVault

A personal movie library that treats Telegram as a 5GB+ cold storage. Next.js UI handles large-file uploads with progress state and metadata capture; a Node + Prisma backend streams the file to Telegram, stores metadata in Postgres, and plays it back through a custom player. Built the way I like my own tools: lean, no vendor lock, works offline where possible.

Frontend
Next.js · TypeScript · Tailwind · UploadSheet component
Backend
Node · Express · Prisma ORM · PostgreSQL
Storage
Telegram Bot API as object store · metadata in Postgres
